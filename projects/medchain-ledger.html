QR Code Generator

The QR Code Generator is a free and easy-to-use web tool that allows users to create QR codes for various types of content, including URLs, text, Wi-Fi credentials, contact information, SMS, emails, calls, and UPI payments. It offers advanced customization options to generate QR codes that are not only functional but also tailored to specific needs. Whether you're a business owner, developer, or individual, this tool makes QR code creation accessible and versatile.


Features:


  • Create QR codes for multiple content types, including URLs, text, Wi-Fi, contact info, SMS, email, call, and UPI payments.
  • Advanced customization options for size, foreground color, background color, and more.
  • Download your QR codes in multiple formats (PNG, SVG, etc.).
  • Option to add custom logos or center images to the QR code for personalization.
  • Responsive design, so you can generate QR codes on mobile, tablet, and desktop devices.
  • Fast, simple interface with no sign-ups or hidden fees—completely free to use.

Advantages:


  • Free and Easy to Use: No sign-up or subscription is required. Just enter the data, customize if needed, and download the QR code instantly.
  • Customizable: Tailor the QR code’s color scheme, size, and image/logo placement to match your brand or design preferences.
  • Multi-Purpose: The tool supports various types of QR codes, making it versatile for businesses, events, personal use, and more.
  • Fast and Reliable: The generator is fast, responsive, and works seamlessly across devices. You can generate high-quality QR codes in seconds.
  • Secure: The QR Code Generator tool operates securely, ensuring that any information you enter is processed safely without any risks of data breaches.

Customization Options:


The QR Code Generator offers advanced customization features that allow you to create QR codes that fit your specific needs. Some of the key customization options include:

  • Quality (px): Set the resolution for your QR code to ensure it's perfect for printing or online use.
  • Foreground & Background Colors: Customize the foreground and background colors of your QR code to make it match your branding or design.
  • Corner Squares & Dots: You can adjust the shape and design of the corner squares and dots of the QR code for a unique appearance.
  • Center Image/Logo: Upload a custom logo or image to place in the center of the QR code for better branding or personalization.
  • Advanced Layout: You can also control the size of the QR code, enabling better control over its visibility on websites, flyers, and more.

Free QR Code API Documentation


Dynamically generate highly customizable, interactive QR codes instantly by passing URL parameters. No API keys or authentication required.


How It Works:

Our QR API utilizes client-side rendering. By formatting an HTTP GET request to our target endpoint, the page instantly grabs your query parameters and renders a beautifully styled QR code on a transparent background.

Base Endpoint: https://qrzip.vercel.app/qrgen.html?[DATA_OR_TYPE]&...


Global Styling Parameters:

Customize the visual appearance of any QR code type by appending these optional parameters to your request.

Parameter Status Description
size Optional Width & height in pixels (Default: 300). Example: size=500
fg Optional Foreground dot color (Hex code without '#'). Example: fg=ff0000
bg Optional Background color (Hex code without '#'). Example: bg=f8f9fa
style Optional Preset patterns: default, dots, square, grounded, classy, classy-rounded, extra-rounded.
logo Optional URL of a center image (Must be URL encoded). Example: logo=https://img.url

pragma solidity ^0.8.0;

contract MedicalRecordRegistry {
    mapping(address => string) private encryptedRecords;
    event RecordUpdated(address indexed patient);

    function updateRecord(string memory _hash) public {
        encryptedRecords[msg.sender] = _hash;
        emit RecordUpdated(msg.sender);
    }
}
